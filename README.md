# Minimol 2026 Problem Statements

This repository contains the official problem statements for Minimol 2026.

## Tracks
* **[P2P Mobile Mesh Inference](p2p.md)** (`p2p.md`): Split transformer forward pass across mobile phones on Web CPU.
* **[Autonomous Intersection Control](traffic.md)** (`traffic.md`): Multi-agent decentralized vehicle navigation at a 4-way intersection.
* **[HiveNet Distributed Edge Storage](storage.md)** (`storage.md`): Standalone peer-to-peer cloud storage with client compression and smart routing.
* **[Reach Together](fresher_track.md)** (`fresher_track.md`): Spatio-temporal travel companion matching with safety guardrails and fair fare splitting.
